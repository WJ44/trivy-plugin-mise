# trivy-plugin-mise

Rust CLI and Trivy plugin bridging `jdx/mise` (`mise.toml`, `mise.lock`,
`.mise/locks/`) with `aquasecurity/trivy` for CycloneDX SBOM generation and
vulnerability scanning. See
[Decision 001](decisions/001-language-and-distribution.md).
