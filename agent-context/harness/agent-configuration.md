# Agent tool configuration

## Prefer portable config

Where a format is understood by multiple AI CLI tools, use it. `AGENTS.md` is
the canonical example — Antigravity discovers it natively, and `CLAUDE.md` is
deliberately just `@AGENTS.md` so the content is shared rather than
tool-specific.

Reach for vendor-specific config (`.claude/settings.json`,
`~/.gemini/antigravity-cli/settings.json`, and friends) only when no shared
equivalent exists, and say so when proposing it.

## Prefer project level over user level

Configuration belongs in this repo so it travels with a clone, not in
`~/.claude`, `~/.gemini`, or other machine-local state. If a setting genuinely
cannot work project-scoped, say so explicitly rather than quietly falling back
to user scope.

## Current vendor-specific config

### Claude Code

`.claude/settings.json` (committed):

- `permissions.defaultMode: "bypassPermissions"` — executes tools without
  interactive confirmation prompts (safe because the environment runs inside a
  sandbox).
- `hooks.PostToolUse`: runs `./hooks/post-edit` after `Edit|Write|MultiEdit`
  tool calls to format and lint the edited file (see
  [Formatting and linting](formatting-and-linting.md#agent-hooks)).

`.claude/settings.local.json` (gitignored, generated by `setup-user.sh`):

- `autoMemoryDirectory` points auto-memory at `memory/` in the repo root, so
  memories are project-level rather than living under `~/.claude/projects/`.

`memory/` sits at the root rather than under `.claude/` so it is not tied to one
vendor.

`.claude/settings.local.json` cannot be committed because `autoMemoryDirectory`
rejects relative paths and is ignored in a checked-in `settings.json`, so
`setup-user.sh` writes the absolute path per clone.

### Antigravity (`agy`)

`~/.gemini/antigravity-cli/settings.json` (user-level, configured by
`setup-user.sh`):

- `toolPermission: "always-proceed"` — executes tools without interactive
  confirmation prompts.
- `trustedWorkspaces: [REPO_ROOT]` — registers the workspace as trusted so local
  rules apply without prompting.

Antigravity isolates execution authority to the user/machine level to prevent
untrusted clones from overriding permission boundaries. Because it does not read
a repo-level `settings.json`, `setup-user.sh` merges these settings into the
environment's `settings.json` via `jq`.

`.agents/hooks.json` (committed):

- Runs `../hooks/post-edit` after file edits (`write_file|edit_file`) to
  automatically format and lint the modified file and report any remaining lint
  errors back to the agent (`PostToolUse` runs the formatter/linter after each
  edit, and `PostInvocation` feeds any unfixable lint errors back into the
  conversation).

## Shared agent hooks (`hooks/`)

Hook scripts that run automatically during an agent session live in `hooks/` at
the repository root. Both `.claude/settings.json` and `.agents/hooks.json`
delegate to these shared scripts rather than duplicating logic per tool.

- `hooks/post-edit`: Runs automatically after an agent edits or writes a file in
  the repository. It formats and lints the modified file via `lefthook`
  (`format` then `lint`) and reports any remaining unfixable lint errors back to
  the agent so they can be fixed immediately.
